# Customer Churn Analysis & Prediction Dashboard

## Results
- Accuracy  : 92.62%
- ROC-AUC   : 0.9739
- High Risk Customers : 775
- Revenue at Risk     : $56,016/mo (57.3%)

## Tools Used
Python | XGBoost | SHAP | Seaborn | Matplotlib

## Key Findings
1. Contract type — #1 churn driver (SHAP)
2. Monthly charges — #2 churn driver
3. Tenure — #3 churn driver
4. Month-to-month customers churn most

## Project Steps
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis (5 charts)
3. XGBoost ML Model Training
4. SHAP Explainability Analysis
5. Business Impact (Revenue at Risk)

## Dataset
Telco Customer Churn — 7,043 records
